## 1. 배경 — 왜 본 작업인가

M1.8 §8.2a-2 가 `now_futures_indicator` 의 신규 9 컬럼 (predicted/last_settled funding + basis + Top Pos LSR + Global LSR) 채움 활성화 — **현재 시점 스냅샷**. 사용자 요구 #3 ("선물 지표 7+ × 인터벌 9+") 의 **시계열 영역** = `history_futures_indicator` 의 backfill 이 본 substep.

|---|---|
| 5m | 5분 봉 |
| 15m | 15분 봉 |
| 30m | 30분 봉 |
| 1h | 1시간 봉 |
| 2h | 2시간 봉 |
| 4h | 4시간 봉 |
| 6h | 6시간 봉 |
| 12h | 12시간 봉 |
| 1d | 일봉 |

### Binance futures-data history endpoint 5종 (M1.8 §8.0 자문 Q1)

- `/futures/data/openInterestHist?symbol=X&period=5m&limit=N` (9 interval 지원)
- `/futures/data/topLongShortAccountRatio` (동일 패턴)
- `/futures/data/topLongShortPositionRatio` (동일)
- `/futures/data/globalLongShortAccountRatio` (동일)
- `/futures/data/takerlongshortRatio` (동일)

→ **5 metric × 9 interval × 608 symbols** 가 본 backfill 의 분량.

### Basis 영역 (선택)

`/futures/data/basis?pair=X&contractType=PERPETUAL&period=Y` 도 9 interval 지원이지만 본 substep 의 5 metric 에 포함 여부는 **사용자 결정** 영역 (자문 권장 = 포함, scope 결정 필요).

## 2. 분량 시뮬레이션 (1회 backfill)

### 2.1 REST 호출 수

```
USDM TRADING 608 symbols × 5 metric × 9 interval = 27,360 REST
```

IP quota 분석:
- `/futures/data/*` 공통 = 1000 req / 5min / IP (M1.4 Step 4.7 실측 + 자문 D17)
- 27,360 / 1000 × 5min = **약 2시간 17분** (rate limit 내 안전)
- M1.8 §8.4-d 적용 후 perSymbolTask 영향: 동시 가동 시 같은 IP bucket 공유 → 본 task 와 perSymbolTask cycle 충돌 가능
- 해결: 본 task 의 첫 backfill 은 perSymbolTask 일시 중단 또는 별도 야간 시간대 실행 (cron 형태)

### 2.2 Row 수

각 interval 14일치 (D3 lookback):

| Interval | row per symbol per metric (14일) |
|---|---|
| 5m | 4032 |
| 15m | 1344 |
| 30m | 672 |
| 1h | 336 |
| 2h | 168 |
| 4h | 84 |
| 6h | 56 |
| 12h | 28 |
| 1d | 14 |
| **합** | **6,734** |

**총 row**: 6,734 × 5 metric × 608 symbols ≈ **20.5M row**

### 2.3 Supabase 용량 영향

- Row 당 평균 ~100 byte (id + recorded_at + 5 metric numeric + PK 3)
- 20.5M × 100 byte = **약 2GB**
- Supabase Pro Tier 데이터 8GB 한도의 25% (안전)
- 인덱스 (recorded_at + PK) 추가 시 +30~50% = ~3GB

### 2.4 메모리 footprint (worker)

- 본 task 가 stream 방식 — 전체 27K 응답을 메모리에 유지 X
- 각 fetcher 호출 결과 즉시 upsert → 메모리 영향 거의 없음 (perSymbolTask 패턴 미러링)
