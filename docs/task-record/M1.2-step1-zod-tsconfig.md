## 📖 비전공자 친화 설명

M1.2는 "AI가 볼 메뉴판 4장의 형식"을 만드는 단계입니다. Step 1은 그 중에서 **재료 구매 + 안전장치 설치**에 해당합니다.

**재료 구매**: Zod라는 라이브러리를 설치했습니다. Zod는 "이 데이터가 올바른 형식인가?"를 자동으로 확인해주는 도구입니다. 식당 비유로 하면, 메뉴판에 적힌 요리 정보가 "이름은 반드시 문자, 가격은 반드시 숫자"처럼 형식을 지키는지 자동 검사해주는 검수원입니다. TRAVIS에서 Zod는 **AI와 코드 사이의 계약서** 역할을 합니다.

**안전장치**: `packages/shared`(공용 코드 폴더)의 TypeScript 설정에서 "DOM"이라는 브라우저 전용 타입을 제거했습니다. 이 폴더는 브라우저(web)와 서버(worker) 양쪽에서 쓰이는데, 실수로 `window.alert()` 같은 브라우저 전용 코드를 쓰면 서버에서 터집니다. DOM을 제거하면 **코드 작성 시점에 바로 빨간줄**이 뜨므로 사고를 미연에 방지합니다.

## 🧭 주요 의사결정 (2건)

1. **Zod 3.x 선택 (4.x 거부)**: Zod 4는 2025년 후반 출시됐으나 아직 생태계 호환성이 불안정. 3.24가 안정판이므로 이것을 사용. M2+ 확장 루프에서 4.x 마이그레이션 검토 가능.

2. **DOM 제거를 tsconfig override로 처리 (base 변경 거부)**: base의 `lib`은 웹 앱 등 다른 패키지에서 여전히 DOM이 필요하므로, shared만 개별 override. 이 패턴은 data-service에도 동일 적용 가능.
