**규칙**: 단위/시간대 같은 라벨("UTC", "8h", "BTC" 등)은 **순수 값 포매터**(예: `formatEventTime`/`formatChartTime`)가 값 문자열에 박아넣지 말고, **화면에 표시되는 지점**이 **1회만** 소유한다. 밀도 높은 셀(피드 라인·표 데이터 셀)에는 라벨을 반복 부착하지 않고, 컬럼 헤더/subtitle 캡션/툴팁 헤더 같은 상위 지점에 한 번만 붙인다.

**Why**: [10-99] UTC 표기 전환에서 확립된 패턴. 청산 피드는 시각이 초 단위로 수백 줄 흐르는데 매 줄 "UTC"를 붙이면 시각적 소음이 된다. 값 포매터를 순수하게 유지하면 소비처마다 라벨 배치를 자유롭게 결정할 수 있고, 테스트도 값만 핀하면 된다(라벨 문자열이 값 스냅샷을 오염하지 않음). 이는 TRAVIS 시맨틱 레이어 철학(값=데이터 / 표시 의미=descriptor·표시 지점)과 한 몸이다.

**How to apply**: 새 포매터/카드 리뷰 시 "라벨이 순수 값에 섞여 있나?"를 자문. 섞여 있으면 → 값 포매터는 순수 값만 반환, 라벨은 헤더/캡션/툴팁 등 표시 지점 1곳으로 이동 권고. AI 자유 텍스트(subtitle)를 건드리지 않고 라벨을 병기할 땐 별도 span 병기가 정석([10-92]① 뱃지 선례, FeedCard "· times UTC" 동형). 관련 감사 절차는 [[time-display-audit-checklist]].
