## 4. 실행 중 실측 버그 3건 (영구 교훈)

1. **200 rate-limit envelope crash**: Binance 가 rate-limit 을 429 아닌 **200 + `{code:-1003}`** 로 반환 → 배열 가정 `.map()` crash. → `isBinanceErrorEnvelope` (mock 테스트 사각지대, 실배포 1회 필수 — `feedback_mock_test_invariant_blind_spot`).
2. **same-IP ban**: production perSymbolTask 와 같은 IP backfill → -1003 IP ban (production 수집도 동시 차단). → **로컬 one-shot(별도 IP) 전환**. `[8-20]` 별도 worker 정공의 실증. `feedback_binance_futures_data_ip_quota`.
3. **sparse 윈도잉**: `/futures/data/*` stat 5종이 범위>limit 시 sampling 반환 → 심볼당 ~500행(basis만 dense). → **고정 폭 윈도우**(endTime=cursor+500×interval) → 6 metric 전부 dense(~4032). **데이터 완전성의 핵심 수정**.
