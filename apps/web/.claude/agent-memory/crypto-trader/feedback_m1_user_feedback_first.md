M1.5 Step 3 crypto-trader 자문에서 사용자가 확정한 원칙: "M1 완료 전에는 내부 가설만 쌓고, 실제 바이낸스 선물 트레이더들이 써본 뒤의 피드백이 들어오기 전까지 UX 방향을 단정하지 말 것."

**Why**: 3년차 트레이더 1인(사용자)의 직관이 강력하긴 하지만, 글로벌 타겟 제품이므로 한국/일본/유럽/북미 등 다양한 현장 트레이더의 수용성은 내부에서 추정할 수 없음. 추정으로 기능을 확정하면 나중에 되돌리는 비용이 큼.

**How to apply**:
- crypto-trader 자문 시 "이건 A 가 낫다 / B 가 낫다" 단정 대신 "A 가설 vs B 가설. M1 완료 후 사용자 테스트로 선별하자" 로 프레이밍.
- 새 기능 제안은 scope 영역이므로 roadmap-milestone-manager 에 위임.
- 사용자가 이미 반박한 방향의 제안 (예: "즉시 i18n 하자", "즉시 로그인 강제하자") 은 반복하지 말 것.
- 관찰 프레임을 "M1 완료 후 사용자 피드백으로 검증" 시나리오 질문으로 마무리.
