**`apps/web/lib/format/marketUnits.ts`** 신설:
- `formatPrice(value: number | null, tickSize?: number | null): string` — symbols.tick_size 기반 소수점 결정. tickSize 미존재 시 적응형 (price < 1 → 6자리 / < 100 → 4자리 / 그 외 2자리).
- `formatFundingRate(raw: number | null, intervalHours?: 4 | 8): string` — `raw × 100` → `"0.0100% (8h)"` 형식. interval 미주입 시 단순 `"0.0100%"`.
- `formatLSR(ratio: number | null): string` — 소수 4자리 `"1.1322"`.
- `formatOI(value: number | null, marketType: "futures_usdm" | "futures_coinm", baseAsset?: string): string` — USDM = `"123.45 BTC"` / COINM = `"1,234 contracts"`.
- `formatBasis(value: number | null, quote: string = "USDT"): string` — `"−35.68 USDT"`.
- `formatBasisRate(raw: number | null): string` — `"0.0200%"` (raw × 100, 4자리).
- `formatCountdown(nextFundingTime: number | null): string` — `Math.floor((next - now) / 3600000)` 시간 + 분 = `"02:13:45"` 또는 `"2h 13m"`.
