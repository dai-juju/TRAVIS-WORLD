### 1-A. `apps/web/lib/tvSymbolMap.ts` — 심볼 매핑 함수 + 주석

**변경 전** (2곳):
```ts
if (marketType === "futures_coinm") return null;   // COIN-M 전면 null (저활용)
return `${prefix}:${symbol}`;                       // USDM = Spot (왜곡 버그)
```

**변경 후** (3-way 분기):
```ts
if (marketType === "futures_coinm") {
  if (!symbol.endsWith("_PERP")) return null;       // delivery → null
  const base = symbol.replace("_PERP", "");         // BTCUSD_PERP → BTCUSD
  return `${prefix}:${base}.P`;                      // BINANCE:BTCUSD.P
}
if (marketType === "futures_usdm") {
  if (symbol.includes("_")) return null;            // delivery → null
  return `${prefix}:${symbol}.P`;                    // BINANCE:BTCUSDT.P
}
return `${prefix}:${symbol}`;                        // Spot 기본
```

파일 상단 주석도 조사 URL 4개 (Spot/USDM.P/COINM.P + 조회일 2026-04-22) 와 USDC-M 정책 (TV 에 맡김) 을 반영하여 전면 갱신.
