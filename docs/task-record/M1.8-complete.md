## 2. 핵심 산출물

- **Schema**: `now_futures_indicator` funding 분리 + basis/basis_rate + `symbols.funding_interval_hours` (런타임 컬럼 존재 확인 ✅, 단 마이그레이션 파일 미기록 → deferred `[8-5]`).
- **worker**: 4 fetcher + `fundingInfoTask`(4h/8h 자동 식별) + `premiumIndexTask` + REST/WS TRADING allowlist 5위치 정합 + `historyBackfillTask`(dry-run 5번째 task 영구 가동).
- **spot 데이터 정합**: `!ticker@arr` full 복귀로 `price_change_pct` 1초 신선 (§8.4-e). `tickerWsHandler.canHandle` marketType 분기 (spot=full, futures=mini).
- **표시 단위 정공**: `apps/web/lib/format/marketUnits.ts` 8 헬퍼 — funding(raw×100% + interval 라벨) / OI(USDM=base asset) / LSR(ratio) / Basis(USD) / Countdown. 트레이더 100배 misread 단일 차단 창구.
- **canonical-metrics.md**: 8 metric 정의 + 거래소별 매핑 + 단위/정밀도 표준 + 13셀 site=DB 매트릭스 + PHAROSUSDT 4h smoke.
