### 7-2. Supabase Free Tier Compute Sleep (환경 이슈)
**증상**: `now_spot_ticker`, `now_futures_ticker` 에 대한 CORS 에러 다수 → 카드 "LOADING" 지속.

**원인**: Supabase Free Tier 프로젝트가 7일 무활동 시 Paused 상태. Paused 상태는 HTTP 응답에 CORS 헤더 없음 → 브라우저가 네트워크 에러로 처리.

**해결**:
1. Supabase 대시보드 접속으로 warm-up 또는 Resume 수동 실행
2. Worker 재가동으로 now_* 테이블에 신규 데이터 upsert
3. 이후 브라우저 새로고침 → Realtime 연결 + 실데이터 반영

**warm-up 체크 주의사항** (2026-04-21 재검증에서 발견):
- `curl https://<project>.supabase.co/rest/v1/` 로 HTTP 401 을 받아도 **프로젝트가 awake 라는 보장은 없다**. Supabase 프록시 레이어가 Paused 상태에서도 인증 실패 401 을 반환하기 때문.
- 정확한 체크: **Supabase 대시보드 → 프로젝트 카드에 "Paused" 배지가 사라져 있는지 육안 확인** 또는 **브라우저에서 anon key 포함 실제 쿼리를 보내 CORS 에러가 없는지** 확인.

### 7-4. TradingView USDM/Spot 심볼 혼동 (code-reviewer W5)
**증상**: `tvSymbolMap.ts`가 `BINANCE:${symbol}`로 일괄 변환. 그러나 TradingView에서 이 포맷은 **spot 차트**로 인식되며, USDM perpetual 차트는 `.P` suffix (`BINANCE:BTCUSDT.P`) 또는 `PERP` suffix가 필요할 수 있음.

**증거**: 다크 스크린샷에서 차트 제목 "Ethereum / TetherUS" 표기 — 사용자는 `marketType: 'futures_usdm'` 의도했으나 spot 차트가 로드된 가능성.

**후속 action**: M1.4 Step 4 진입 시 `@crypto-domain-expert` 자문으로 TV USDM/Spot/COIN-M 정확한 심볼 포맷 확정 후 `tvSymbolMap.ts` 수정. 동시에 KlineChartCard에 "spot/perp" 배지 노출 검토.

### 7-5. AI 자유 텍스트 HTML sanitize 부재 (code-reviewer W2)
**증상**: `TickerCard`/`CoinListCard`/`KlineChartCard` 헤더의 `dangerouslySetInnerHTML` 호출. AI가 생성하는 title 문자열에 `<em>` 외 임의 HTML이 포함되면 XSS 가능성.

**현재 방어**: `AiCardConfigSchema`의 `.max(80)` 길이 제약뿐. Zod로 HTML sanitize 불가.

**후속 action**: 간이 parser로 `<em>` 태그만 화이트리스트 허용하는 sanitize 레이어 추가 (또는 `isomorphic-dompurify` 도입). M1.6 security-auditor 자문 전까지 임시 방어선 확보 권장.

### 7-3. TradingView iframe 테마 전환 지연
**증상**: 다크 → 라이트 전환 시 TradingView 차트 내부 테마가 즉시 바뀌지 않고 이전 상태 잔상 일부 유지.

**원인**: iframe `key` 속성 변경으로 React는 리마운트를 수행하지만, TradingView widget 내부 초기화가 비동기(~1~2초)라 시각적 지연 발생.

**개선안 (M1.5+ 이월)**:
- TradingView widget `postMessage` API 활용 → iframe 전면 리로드 없이 테마만 변경
- 또는 iframe src에 `timestamp=` 쿼리 추가해 브라우저 캐시 완전 무효화

기능은 작동(새 src로 재로드) — 시각적 매끄러움 이슈만.
