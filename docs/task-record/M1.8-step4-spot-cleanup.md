### Phase 2 (DB cleanup) — 사용자 Supabase Studio SQL Editor 실행 예정

옛 stale row 일회성 DELETE. SQL:

```sql
-- M1.8 §8.4 — SPOT/Futures stale row cleanup (2026-05-26)
-- now_*_ticker / now_futures_indicator 에서 symbols 의 TRADING 상태가 아닌 row 일괄 삭제.

DELETE FROM now_spot_ticker
WHERE NOT EXISTS (
  SELECT 1 FROM symbols s
  WHERE s.exchange = now_spot_ticker.exchange
    AND s.market_type = now_spot_ticker.market_type
    AND s.symbol = now_spot_ticker.symbol
    AND s.status = 'TRADING'
);

DELETE FROM now_futures_ticker
WHERE NOT EXISTS (
  SELECT 1 FROM symbols s
  WHERE s.exchange = now_futures_ticker.exchange
    AND s.market_type = now_futures_ticker.market_type
    AND s.symbol = now_futures_ticker.symbol
    AND s.status = 'TRADING'
);

DELETE FROM now_futures_indicator
WHERE NOT EXISTS (
  SELECT 1 FROM symbols s
  WHERE s.exchange = now_futures_indicator.exchange
    AND s.market_type = now_futures_indicator.market_type
    AND s.symbol = now_futures_indicator.symbol
    AND s.status = 'TRADING'

-- 검증
SELECT 'now_spot_ticker' AS tbl, COUNT(*) AS total FROM now_spot_ticker
UNION ALL SELECT 'now_futures_ticker', COUNT(*) FROM now_futures_ticker
UNION ALL SELECT 'now_futures_indicator', COUNT(*) FROM now_futures_indicator;
```
