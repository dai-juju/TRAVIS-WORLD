## 1. 배경 — 왜 hotfix 인가

## 2. 변경 파일 7건

### 2.1. 🔴 Production code (3 files)

#### `apps/worker/src/ws-relay/streams/markPriceWsHandler.ts:111`
```diff
- last_funding_rate: parseNum(r.r),
+ predicted_funding_rate: parseNum(r.r),
```
**의미**: WS `markPriceUpdate.r` 필드는 **predicted next funding rate** (1초 변동, Binance 사이트 우상단 funding(4h)/Countdown 박스의 큰 숫자). D8 결정에 따라 `predicted_funding_rate` 컬럼으로 매핑. 자문 인용 주석 추가.

#### `apps/worker/src/adapters/binance/normalize.ts` (USDM premium, line 215 영역)
```diff
- last_funding_rate: num(raw.lastFundingRate),
+ last_settled_funding_rate: num(raw.lastFundingRate),
```
**의미**: REST `premiumIndex.lastFundingRate` 필드는 docs verbatim "Latest funding rate" — **realized last settled** (정산 직후 4h/8h 동안 고정). D8 결정에 따라 `last_settled_funding_rate` 컬럼으로 매핑. 시간축이 WS `r` 과 다른 별개 metric.

#### `apps/worker/src/adapters/binance/normalize.ts` (COINM premium, line 366 영역)
USDM 과 동일 정합.
