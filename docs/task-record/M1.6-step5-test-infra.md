### 잠복 버그 [3-61] — 테스트 작성 중 자연 발견

**한 줄**: 로그인/회원가입 버튼을 0.05초 안에 두 번 광클릭하면 서버에 두 번 호출이 가는 race condition.

자세히:
- 사용자가 "Sign in" 누름 → `if (submitting) return; setSubmitting(true); ...`
- 그런데 React 는 `setSubmitting(true)` 직후에도 화면이 다시 그려지기 전까지 약간 시간차 (몇 ms)
- 그 시간차 안에 두 번째 클릭이 들어오면, 두 번째 onSubmit 함수가 캡처한 `submitting` 변수는 여전히 `false` (옛 값)
- 결과: signIn 두 번 호출 → 회원가입은 "이미 가입됨" 에러 가능

ChatInputBar 는 이미 `[2-6]` 회수로 `submittingRef = useRef(false)` 동기 가드 추가해 해결됨 — Login/SignupForm 은 같은 패턴 누락. **테스트 작성 중에 깨달음** = 본 PR 의 진짜 가치.

→ 즉시 fix 하지 않은 이유: production 코드 변경은 별도 commit scope 가 정공 (CLAUDE.md "한 번에 하나의 작업"). `[3-61]` 로 deferred 등록, 다음 commit (~30분 작업) 회수 예정. 본 PR 의 (iv) 테스트는 disabled-attribute 1차 방어선만 검증.
